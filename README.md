## SIMBA

Sistem Informasi Akademis Lembaga adalah sebuah aplikasi web yang dapat digunakan untuk mengelola data akademik lembaga. Aplikasi ini dibuat dengan menggunakan framework Laravel dan Tailwind CSS.

Fitur: 
- Manajemen Siswa
- Manajemen Rombel
- Manajemen Presensi
- Manajemen Pembelajaran
- Manajemen Jadwal
- Manajemen Pelajaran
- Manajemen Tahun Ajaran
- Manajemen Pengguna
- Manajemen Pengaturan
- Manajemen Database

## Cara Install

1. Clone repository: `git clone <https://github.com/amuadib/simba.git>`
2. Install Laravel: `composer install`
3. Install Tailwind CSS: `npm install`
4. Generate Key: `php artisan key:generate`
5. Compile Tailwind CSS: `npm run build`
6. Setup Environment: `cp .env.example .env`
7. Buat database: `php artisan migrate`
8. Setup akun admin: `php artisan user:create`
7. Jalankan server: `php artisan serve`
